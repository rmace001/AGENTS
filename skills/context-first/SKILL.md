# Context First

Use this skill when the user wants a prompt reorganized so the context precedes the request. If the user has not provided the prompt, ask them to share it. Otherwise, work from the prompt in their message. 

Identify the contextual information: inputs, their sources and relationships, and any constraints or conditions. Identify the actionable request: what the prompt asks its reader to do. Rewrite the prompt with context first and the request or instruction last. Preserve the original meaning and all details; do not add, remove, or reinterpret content. Keep the result concise and natural-sounding.

Return only the restructured prompt in a fenced code block so the user can copy it directly.
